# Interval Calculator

A lightweight, precise tool designed to calculate the distance between two points—whether they are numerical ranges, dates, or time intervals. This project focuses on accuracy and ease of use for quick technical calculations.

## 🚀 Features
*   **Numerical Intervals:** Calculate the difference between two integers or floating-point numbers.
*   **Set Logic:** Determine the intersection, union, or gap between two overlapping ranges.
*   **Validation:** Built-in logic to handle edge cases like empty sets or inverted ranges (e.g., when the end is smaller than the start).
*   **Clean Interface:** Designed for quick input and immediate results.

## 🛠 Usage
Simply enter your "Start" and "End" points. The calculator will provide:
1.  **The Magnitude:** The absolute distance between the points.
2.  **Midpoint:** The exact center of the interval.
3.  **Visualization:** A simple text-based representation of the range.
